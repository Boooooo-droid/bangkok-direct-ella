# BOOT · CORRUPTED SAVE

Unofficial fan experience inspired by [nulls](https://x.com/nullsxyz) on NEAR.

Walk five childhood-memory vignettes, make choices, and leave with a generated **Memory Fragment** card you can save and share.

This does **not** grant official whitelist. Apply at [nulls.world/apply](https://nulls.world/apply).

## Run locally

```bash
cd nulls-memory-run
python3 -m http.server 8765 --bind 127.0.0.1
```

Open `http://127.0.0.1:8765`
