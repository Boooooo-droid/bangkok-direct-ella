# NULL RUN

Unofficial Vector-style parkour fan game using public visuals from [nulls.world](https://nulls.world).

- Pick a Nulls silhouette crew member
- Press PLAY → auto-run
- Jump / slide past project-themed obstacles
- Escape STATIC, collect memory cards, share score on X
- No login

Not affiliated with nullsxyz.

## Play locally

```bash
cd null-crew-endless
python3 -m http.server 8777 --bind 127.0.0.1
```

Open `http://127.0.0.1:8777`
