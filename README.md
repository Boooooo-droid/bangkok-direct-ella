# Bangkok Direct by Ella — Online Catalog

Mobile-first Burmese clothing catalog. Order buttons open Facebook Page Messenger.

## Live
GitHub Pages URL will be:
`https://boooooo-droid.github.io/bangkok-direct-ella/`

## Owner guide (မြန်မာ)

### Link မျှဝေရန်
- Website link ကို Facebook Page / Telegram / Viber မှာ ပို့ပါ။
- Link က အမြဲ ပွင့်နေမယ် (GitHub Pages)။

### ပစ္စည်းအသစ် တင်ရန် (နေ့တိုင်း)
**အလွယ်ဆုံး:** ပုံတွေ + အမည် + ဈေး (ရှိရင်) + size/color ကို ဒီ chat (Grok Bot) ကို ပို့ပါ → website ပေါ် တင်ပေးမယ်။

**Admin စာမျက်နှာ:** `/admin.html`  
- Password ပုံသေ: `ella2026` (`js/config.js` မှာ ပြောင်းနိုင်)
- GitHub Pages က static မို့ တိုက်ရိုက် upload သိမ်းမရ။ Draft ထုတ်ပြီး chat ကို ပို့ပါ။
